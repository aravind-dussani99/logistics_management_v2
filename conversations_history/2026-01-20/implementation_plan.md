# Implementation Plan: Site Manager & Payments Enhancement

## Overview

This plan addresses two main areas of improvement:
1. **Trip Rates Page**: Update pagination display format to show "Showing X–Y of Z" format
2. **Payments Page**: Major enhancement including new tracking fields, attachment uploads, and improved UX

## User Review Required

> [!IMPORTANT]
> **Database Schema Changes**: The Payment schema will be modified to add new fields (`paymentReceiptUpload`). This requires a database migration that will be auto-generated by Prisma.

> [!IMPORTANT]
> **Breaking Changes**: The "Site Expense" checkbox will be removed. Rate Party Type and Rate Party fields will become required fields instead of optional.

> [!NOTE]
> **Attachment Storage**: Payment receipts will be stored in the existing `*-attachments` Google Cloud Storage bucket under the path structure: `{date}/payments/{date}_{ratePartyType}_{ratePartyName}_{tripId}.{ext}`
> 
> Example: `2026-01-19/payments/2026-01-19_vendor-customer_ABC_Corp_123.pdf`
